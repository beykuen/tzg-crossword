# 田字格填字

在 iPad 上玩的中文填字遊戲。用 Safari 打開網頁就能玩，也可以「加入主畫面」。

- 8 個主題：食物、動物、台灣地理、職業、運動、成語、二年級國語（南一二上）、五年級國語
- 三種難度：簡單（預填約 40% 的字）、中等（約 20%）、困難（不預填）
- 每按一次「新題目」就隨機排一張新格子
- 完成時依正確度（70 分）和速度（30 分）評分，蓋甲上、甲、乙、丙印章；按「看全部答案」不蓋章
- 「自訂詞庫」可以自己加詞；在這個網站上，自訂的詞只存在目前這台裝置的瀏覽器裡

整個遊戲是單一檔案 `index.html`，不需要安裝或建置。

## 屬性對決（`cards/`）

兩人各用一台裝置連線對戰的卡牌遊戲：水剋火、火剋冰、冰剋水，同屬性比等級（1～9）。一人開房間拿到 4 位數房號，另一人輸入房號加入。網址：https://beykuen.github.io/tzg-crossword/cards/
